# Webtoon MT Judge

만화 · 웹툰 기계 번역(MT, 일→한)과 식자(번역문을 말풍선에 넣는 것)를 LLM/VLM이 채점할 때, **그 점수가 사람 판단과 얼마나 맞는지**를 재본 작은 실험입니다.

Kimura & Suzuki의 [*Text-Only vs. Image-Aware VLM Judges for Manga Translation Evaluation*](https://arxiv.org/abs/2610.17908)은 같은 VLM에 페이지 이미지를 보여 줄 때와 보여 주지 않을 때의 판정을 비교했지만, 판정과 사람 평가의 일치도는 수치로 보고하지 않았습니다. 이 실험은 그 설계를 작은 규모로 옮기고, 빠진 **판정–사람 일치도**를 측정합니다.

## 설계 (결과를 보기 전에 고정)

| 항목 | 내용 |
|---|---|
| 데이터 | OpenMantra (CC BY-NC 4.0), 5개 작품 7쪽 · 말풍선 40개. 고정 시드로 선택 (`src/select_pages.py`) |
| 인물 관계표 | 쪽마다 인물 · 관계 · 원문의 경어 수준을 정리한 설정 자료(`data/context.json`). 번역 시스템은 보지 않고, 판정 모델과 사람 평가자만 봄 |
| 번역 시스템 | S1 Claude Opus · 페이지 이미지 + 쪽 단위 / S2 Claude Haiku · 페이지 이미지 + 쪽 단위 / S3 Claude Sonnet · 이미지 없이 한 줄씩 |
| 자동 판정 | Claude Sonnet, Claude Opus × {텍스트만, 페이지 이미지 포함}. 참조 번역 없이 원문 + 인물 관계표로 1–5점 + 오류 태그 |
| 사람 평가 | 1명(작성자), 시스템을 가린 블라인드 평가표, 같은 1–5점 기준 + 인물 관계표. 평가자는 일본어 대신 공식 영어 번역(참조)으로 뜻을 확인 |
| 일관성 점검 | 8개 말풍선을 끝에 다시 섞어 넣어 평가자 자신의 재평가 일치도 측정 |
| 지표 | 말풍선×시스템 단위 Spearman · Kendall, 같은 말풍선 안 두 번역의 우열 일치율(pairwise accuracy), 말풍선 단위 부트스트랩 95% 구간 |

## 설계를 바꾼 이유

처음에는 인물 관계 정보 없이 평가했지만, 평가를 시작해 보니 쪽 하나만으로는 인물 관계를 알 수 없어 **반말 · 존댓말이 맞는지 판단할 수 없었습니다.** 한국어 번역에서 경어 수준은 품질의 핵심이라, 관계를 모른 채 내린 점수는 사람의 것이든 모델의 것이든 믿기 어렵습니다. 그래서 실제 현지화 작업의 설정 자료처럼 쪽마다 인물 관계표를 만들어 판정 모델과 평가자에게 똑같이 주고 다시 평가했습니다. 관계표 없이 돌린 첫 판정은 `runs/v1_before_tone_rule/`에 남겨 두었습니다.

## 실행 방식

이번 결과의 번역과 판정은 **Claude 모델을 에이전트 세션에서 같은 프롬프트(`prompts/`)로 실행**해 만들었습니다(API 키 없이 진행). 각 모델은 자기 입력 파일만 보도록 분리했고, 판정 모델은 시스템 이름과 참조 번역을 보지 못했습니다. API로 다시 돌리거나 다른 모델(예: HyperCLOVA X)을 추가할 때는 `src/run_api.py`를 씁니다.

```
python src/select_pages.py <open-mantra-dataset 경로>   # 평가셋
python src/blind.py                                     # 번역 결과 섞기 → judge_input.json
python src/build_sheet.py                               # 사람 평가표
python src/analyze.py                                   # 일치도
```

## 결과

사람 평가 120개(말풍선 40 × 번역 3) 기준입니다. 구간은 말풍선 단위 부트스트랩 95%입니다.

| 판정 | Spearman ρ (95% 구간) | 우열 일치율 (95% 구간) |
|---|---|---|
| Sonnet · 텍스트만 | **0.36** (0.12 – 0.58) | **0.63** (0.56 – 0.71) |
| Sonnet · 이미지 포함 | 0.31 (0.08 – 0.53) | 0.61 (0.52 – 0.69) |
| Opus · 텍스트만 | 0.31 (0.06 – 0.53) | 0.60 (0.53 – 0.67) |
| Opus · 이미지 포함 | 0.30 (0.05 – 0.52) | 0.60 (0.52 – 0.67) |
| 참고: 평가자 본인 재평가 (8개 말풍선) | 0.69 | 같은 점수 71% |

여기서 사람 점수는 정답이 아니라 **비교 기준**입니다. 평가자 1명의 판단도 틀릴 수 있어서(3번), "판정이 맞았다/틀렸다"가 아니라 "사람과 얼마나 같게 봤나"를 잽니다. 평가자가 같은 말풍선을 다시 매긴 일관성(0.69)이 이 기준이 가진 흔들림의 크기입니다.

우열 일치율은 같은 말풍선의 두 번역 중 어느 쪽이 나은지를 사람과 같게 고른 비율입니다(사람이 동점을 준 쌍 제외, 76쌍).

**1. 판정은 사람 판단과 약하게만 맞았습니다.** 네 판정 모두 ρ 0.30–0.36으로, 평가자가 스스로를 다시 평가했을 때의 일관성(0.69)에 한참 못 미칩니다. 판정 점수를 사람 점수 대신 그대로 쓰기는 어렵습니다.

**2. 판정은 "어색함"을 거의 잡지 못했습니다.** 판정은 120개 중 70–77%에 5점을 줬고, 사람은 48%였습니다. 점수 차가 2점 이상 난 사례 대부분이 사람은 "뜻은 맞지만 한국어로 어색하다"며 3점을 주고 판정은 5점을 준 경우였습니다(예: 「정말로 우주까지 올라간 걸까요」, 「그 불쌍한 건맨은...」).

**3. 말투 오류는 판정이 오히려 더 일관되게 잡았습니다.** 인물 관계표에 "소노야마는 존댓말"이라고 적힌 장면에서 반말 번역(「아, 아냐!」)을 판정 4개는 모두 2–3점으로 깎았지만 평가자는 5점을 줬습니다. 사람도 설정을 놓칠 수 있고, 규칙이 명확한 항목은 판정이 보조 검수로 쓸모 있다는 뜻입니다.

**4. 인물 관계표를 주자 일치도가 조금 올랐습니다.** 관계표 없이 돌린 첫 판정은 ρ 0.24–0.29였고, 관계표를 준 판정은 0.30–0.36이었습니다. 구간이 겹쳐서 확정할 수는 없지만, 네 판정 모두 같은 방향이었습니다.

**5. 이미지를 보여 줘도 나아지지 않았습니다.** 같은 모델에서 이미지 포함과 텍스트만의 차이는 ±0.05 안이었습니다. Kimura & Suzuki의 "이미지 판정이 항상 낫지는 않다"는 결론과 같은 방향입니다. 이 데이터에서는 그림보다 인물 관계 같은 설정 정보가 더 중요했습니다.

**6. 시스템 순위는 대체로 맞았습니다.** 사람은 S1(Opus · 이미지) > S3(Sonnet · 한 줄씩) > S2(Haiku · 이미지) 순으로 평가했고, 판정 4개 중 3개가 같은 순위를 냈습니다. 개별 말풍선 점수는 믿기 어려워도 시스템 평균 비교에는 쓸 여지가 있습니다.

### 판정 개선: 점수를 뜻 · 자연스러움 · 말투로 나누기 (v3)

2번 문제를 줄이려고, 결과를 보기 전에 계획(`runs/v3_decomposed/PLAN.md`)을 먼저 적고 판정을 다시 돌렸습니다. 한 점수 대신 뜻 · 자연스러움 · 말투를 따로 매기게 하고(`prompts/judge_v3.md`), 전체 점수는 셋 중 가장 낮은 값으로 정했습니다. 성공 기준은 "같은 모델의 기존 판정보다 사람과의 Spearman · 우열 일치율이 높다"였습니다.

| 판정 (텍스트만) | 5점 비율 | 사람이 "어색함"이라 한 36개 중 잡은 비율 | Spearman ρ | 우열 일치율 |
|---|---|---|---|---|
| Sonnet · 기존 | 75% | 33% | 0.36 | 0.63 |
| Sonnet · 나눠서 (최솟값) | **53%** | **58%** | 0.36 | 0.64 |
| Opus · 기존 | 76% | 31% | 0.31 | 0.60 |
| Opus · 나눠서 (최솟값) | 71% | 36% | 0.35 | 0.63 |
| 참고: 사람 | 47% | – | – | – |

- **후한 점수와 어색함 놓침은 줄었습니다.** 특히 Sonnet은 5점 비율이 사람 수준에 가까워졌고, 어색한 번역을 잡는 비율이 33% → 58%로 올랐습니다.
- **전체 일치도는 확실히 올랐다고 말할 수 없습니다.** 같은 말풍선을 다시 뽑아 비교한 차이의 95% 구간이 Sonnet ρ −0.18 – +0.18, Opus ρ −0.06 – +0.17로 0을 포함합니다. 미리 정한 성공 기준은 충족하지 못했습니다.
- 자연스러움 점수만 쓰면 ρ 0.39(Sonnet) · 0.37(Opus)로 가장 높았지만, 이건 결과를 본 뒤의 비교라 참고로만 둡니다. 세 점수의 평균은 오히려 기존보다 후해졌습니다.

정리하면, 점수를 나누는 것은 "어색한데 5점"을 거르는 데는 효과가 있었지만, 사람의 순위 판단 전체를 따라가게 만들지는 못했습니다.

## 식자(typesetting) 평가: 말풍선에 넣는 방식

번역문이 같아도 말풍선에 어떻게 넣느냐에 따라 읽기 편한 정도가 달라집니다. 일본어 원문은 세로쓰기라 글상자가 좁고 길어서, 한국어 가로쓰기를 그 자리에 그대로 넣으면 단어가 끊기거나 글자가 작아집니다. 그래서 **같은 번역문을 넣는 방식만 바꿔** 사람이 느끼는 식자 품질이 어떻게 달라지는지, 그리고 VLM 판정과 단순 규칙 지표 중 무엇이 사람 판단을 더 잘 따라가는지 봤습니다. 계획은 결과를 보기 전에 `runs/typeset/PLAN.md`에 적었습니다.

| 항목 | 내용 |
|---|---|
| 번역문 · 글꼴 | 번역 평가 1위 S1 번역문 고정, 원문 지우기 · 글꼴(Gothic A1 Bold) 고정 |
| 방식 | T1 원래 글상자 + 글자 단위 줄바꿈 / T2 원래 글상자 + 어절 단위 줄바꿈 / T3 말풍선 영역을 찾아 그 폭에 맞게 어절 단위 + 줄 길이 균형 (`src/typeset.py`) |
| 사람 평가 | 말풍선 40개 × 방식 3개를 A · B · C로 가리고 순서를 섞은 평가표, 1–5점 + 태그. 원본 조각도 함께 표시. 6개 말풍선은 끝에 다시 넣어 재평가 |
| VLM 판정 | Claude Sonnet, Claude Opus가 같은 조각 이미지를 같은 기준으로 채점(`prompts/judge_typeset.md`). 번역 내용은 평가하지 않음 |
| 규칙 지표 | 코드로 잰 글자 크기(px), 단어 중간 끊김 수, 글과 선 사이 최소 간격(px) (`runs/typeset_metrics.json`) |

```
python src/typeset.py <open-mantra-dataset 경로>        # 세 방식으로 식자 + 규칙 지표
python src/typeset_sheet.py <open-mantra-dataset 경로>  # 가린 조각 이미지 · 사람 평가표
python src/analyze_typeset.py                           # 결과
```

### 결과

방식별 사람 점수 (말풍선 40개)

| 방식 | 평균 | 4점 이상 비율 | 사람이 가장 많이 단 태그 |
|---|---|---|---|
| T1 글상자 · 글자 단위 | 3.78 | 50% | 줄 나눔 어색 24, 테두리에 붙음 8 |
| T2 글상자 · 어절 단위 | 4.32 | 80% | 글자 작음 10, 줄 나눔 어색 7 |
| T3 말풍선 폭 · 어절 · 균형 | 4.32 | 92% | 글자 작음 8, 치우침/빈 공간 6 |

사람 점수와의 일치 (말풍선 120개, 우열은 사람이 동점을 주지 않은 74쌍)

| 채점 방법 | Spearman ρ (95% 구간) | 우열 일치율 (95% 구간) |
|---|---|---|
| VLM Sonnet | **0.65** (0.51 – 0.76) | **0.83** (0.73 – 0.91) |
| VLM Opus | 0.35 (0.14 – 0.56) | 0.75 (0.67 – 0.82) |
| 규칙: 단어 중간 끊김이 적을수록 | 0.58 (0.46 – 0.69) | 0.74 (0.68 – 0.80) |
| 규칙: 글자가 클수록 | 0.06 (−0.15 – 0.26) | 0.45 (0.35 – 0.56) |
| 규칙: 테두리와 간격이 넓을수록 | −0.03 (−0.24 – 0.19) | 0.43 (0.29 – 0.57) |
| 참고: 평가자 본인 재평가 (6개 말풍선) | 0.74 | 같은 점수 78% |

**1. 어절 단위로만 끊어도 점수가 확실히 올랐습니다.** T2 · T3는 T1보다 평균 0.55점 높았고(95% 구간 T3−T1 0.23 – 0.88, T2−T1 0.30 – 0.83), T1에는 "줄 나눔 어색" 태그가 24번 붙었습니다. T3와 T2의 평균 차이는 0(−0.35 – 0.35)이라 말풍선 폭에 맞추는 효과는 확인하지 못했습니다. 4점 이상 비율은 T3가 더 높았지만(92% vs 80%) 구간을 따로 재지 않았으니 참고로만 둡니다.

**2. 식자 판정은 번역 판정보다 사람과 훨씬 잘 맞았습니다.** 같은 평가자 · 같은 말풍선에서 번역 판정은 ρ 0.30–0.36이었지만, Sonnet 식자 판정은 0.65로 평가자 재평가 일관성(0.74)에 가까웠습니다. 식자는 "단어가 끊겼다, 글자가 작다"처럼 눈에 보이는 기준이 많아서 판정이 쉬운 과제로 보입니다. 다만 과제가 달라 두 숫자를 같은 잣대로 보기는 어렵고, 재평가는 6개 말풍선뿐이라 기준선 자체가 넓게 흔들릴 수 있습니다.

**3. 큰 모델이 더 나은 판정자는 아니었습니다.** Opus는 우열(같은 말풍선 안 순서)은 0.75로 꽤 맞췄지만 전체 ρ는 0.35로 Sonnet보다 낮았습니다. Opus는 평균 3.06점으로 사람(4.14)보다 훨씬 박하게 줬고, 2점 이하가 120개 중 47개였습니다. 말풍선 사이의 점수 높낮이를 사람과 다르게 매긴 것이 원인으로 보입니다. Opus는 20개씩 두 번에 나눠 돌렸는데, 두 묶음의 평균(2.98 · 3.13)과 사람 평균(4.18 · 4.10)의 차이는 비슷해서 나눠 돌린 영향은 커 보이지 않습니다.

**4. 단순 규칙 하나가 Opus 판정만큼 맞았습니다.** "단어 중간 끊김 수"만으로 ρ 0.58 · 우열 0.74가 나왔습니다. 끊김이 대부분 T1에 몰려 있어서 사실상 "T1인가"를 알려 주는 지표에 가깝습니다. 반면 글자 크기 · 테두리 간격은 점수와 거의 관계가 없었습니다. 그래도 사람이 "글자 작음"을 단 칸은 실제 글자가 작았고(19.3px vs 22.5px), "테두리에 붙음"을 단 칸은 실제 간격이 좁았습니다(8.7px vs 12.2px). 규칙은 문제의 **종류**는 잡지만, 그 문제가 점수를 얼마나 깎는지는 사람마다 · 말풍선마다 달라 점수 예측에는 약했습니다.

정리하면, 식자처럼 눈으로 확인할 수 있는 기준은 VLM 판정을 1차 검수로 쓸 만했고, 그중에도 모델에 따라 차이가 컸습니다. 판정을 쓰기 전에 사람 평가와 맞춰 보는 단계가 필요하다는 점은 번역 평가와 같습니다.

### 판정 보정: 사람 평가 8개를 예시로 주기

3번에서 Opus는 순서는 꽤 맞히면서 전체 ρ가 낮았습니다. Spearman은 점수를 일정하게 올리거나 내려도 바뀌지 않으니, 단순히 박하게 준 것만으로는 설명되지 않습니다. 말풍선마다 기준이 흔들렸을 수 있어서, **사람 평가 몇 개를 예시로 보여 주면 기준이 맞춰지는지** 봤습니다. 계획은 결과 전에 `runs/typeset_calib/PLAN.md`에 적었습니다.

- 말풍선 40개 중 8개를 시드 고정으로 뽑아(`src/calib_split.py`) 그 이미지와 사람 점수 · 태그를 프롬프트에 예시로 넣고(`prompts/judge_typeset_calib.md`), 나머지 32개만 평가했습니다.
- 같은 32개에서 기존 판정과 비교했습니다. 성공 기준은 "Opus의 ρ 차이 95% 구간이 0보다 위"였습니다.

| 판정 (평가 32개) | 평균 점수 | Spearman ρ (95% 구간) | 우열 일치율 (95% 구간) |
|---|---|---|---|
| Opus · 기존 | 3.04 | 0.35 (0.10 – 0.60) | 0.73 (0.64 – 0.83) |
| Opus · 예시 8개 | 4.01 | **0.73** (0.60 – 0.83) | 0.81 (0.71 – 0.90) |
| Sonnet · 기존 | 3.47 | 0.62 (0.46 – 0.76) | 0.81 (0.70 – 0.92) |
| Sonnet · 예시 8개 | 4.19 | 0.55 (0.36 – 0.71) | 0.70 (0.59 – 0.82) |
| 참고: 사람 | 4.08 | – | – |

- **Opus는 예시를 주자 크게 좋아졌습니다.** ρ 차이 +0.37 (0.11 – 0.65)로 미리 정한 기준을 넘었고, 평가자 재평가 일관성(0.74)과 비슷한 수준이 됐습니다. 평균 점수도 사람과 거의 같아졌고, 세 후보에 모두 같은 점수를 준 말풍선이 11개에서 6개로 줄었습니다.
- **Sonnet은 오히려 나빠졌습니다.** ρ 차이 −0.07 (−0.24 – 0.10)이고, 우열 일치율은 −0.11 (−0.21 – −0.02)로 떨어졌습니다. 점수가 사람보다 후해지면서(4.19) 차이를 덜 가려낸 것으로 보입니다.
- 즉 예시는 원래 기준이 사람과 많이 어긋난 판정에는 도움이 됐지만, 이미 사람과 비슷하던 판정에는 도움이 되지 않았습니다. 판정 모델마다 보정이 필요한지 따로 확인해야 한다는 뜻입니다.
- 주의할 점: 기존 판정과 예시 판정은 서로 다른 실행이라, 같은 프롬프트를 다시 돌렸을 때 생기는 흔들림이 차이에 섞여 있을 수 있습니다. 예시 선택도 한 번(8개)뿐입니다.

### 식자 평가의 한계

- 식자는 사람 식자가가 아니라 코드로 만든 세 방식이라, 실제 서비스 식자보다 단순합니다. 효과음 · 손글씨 · 말풍선 밖 글자는 다루지 않았습니다.
- 평가자 1명, 재평가 6개 말풍선으로 기준선이 넓습니다.
- 짧은 대사는 두 방식의 결과가 똑같이 나오기도 해서, 사람이 같은 점수를 준 쌍을 빼면 우열을 비교할 수 있는 쌍은 120쌍 중 74쌍입니다.
